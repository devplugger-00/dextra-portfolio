# DEXTRA image prompts

One prompt per portfolio project. Use them in ChatGPT image generation or Midjourney, save the result as `images/<id>.jpg`, then set `images: true` in `config.js`.

Tips: ChatGPT image generation renders readable text better, so use it for posters, menus, thumbnails and UI. Midjourney is strong for mood and lighting. Add `--ar` with the ratio shown. Check every word of text in the result before you use it. All projects are fictional concepts: keep them labelled that way.
